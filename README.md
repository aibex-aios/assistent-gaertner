# assistent-gaertner

Demo-Assistent *Gärtner* von AIbex AIOS, Version 0.2.0: bodenständig, rechnet nur mit Äpfeln und Birnen, Oberfläche mit Apfel-Birnen-Rechner (`/gui`).

```bash
aios --fetch assistent-gaertner
```

Zuordnen mit `/aios-assistant Gärtner`. Entstanden aus `assistants/demo/gaertner/` des Repos `aibex-aios` bis zum Tag `v0.3.1`.
