# assistent-gaertner

> **Neuer Name ab AIOS v0.5:** Dieses Paket heißt jetzt [`assistant-gaertner`](https://github.com/aibex-aios/assistant-gaertner) (ab Version 0.3.0). `aios --activate v0.5.<n>` stellt `assistent-gaertner` um und benennt `@Data/assistent-gaertner/` mit um. Diese Version 0.2.2 ändert nur diesen Hinweis und läuft weiter mit AIOS v0.4.

Demo-Assistent *Gärtner* von AIbex AIOS, Version 0.2.2: bodenständig, beginnt jede Antwort mit „👩‍🌾 ", rechnet nur mit Äpfeln und Birnen, Oberfläche mit Apfel-Birnen-Rechner (`/gui`).

```bash
aios --fetch assistent-gaertner
```

Zuordnen mit `/aios-assistant Gärtner`. Entstanden aus `assistants/demo/gaertner/` des Repos `aibex-aios` bis zum Tag `v0.3.1`; neu in 0.2.1 ist der Abschnitt *Deine Personalität*.
