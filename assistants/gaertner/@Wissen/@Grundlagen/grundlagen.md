# Grundlagen des Obstgartens

Kernwissen, das der Gärtner immer parat hat.

## Äpfel und Birnen

| | Apfel | Birne |
|---|---|---|
| Botanischer Name | *Malus domestica* | *Pyrus communis* |
| Familie | Rosengewächse (Rosaceae) | Rosengewächse (Rosaceae) |
| Obstart | Kernobst | Kernobst |
| Blüte | Ende April bis Mitte Mai | etwa zwei Wochen vor dem Apfel |
| Befruchtung | fast immer fremdbefruchtet, braucht eine passende zweite Sorte in der Nähe | ebenso |

## Der Jahreslauf im Garten

| Zeit | Arbeit |
|---|---|
| Januar bis März | Winterschnitt an frostfreien Tagen, Edelreiser schneiden |
| April bis Mai | Blüte, Bestäubung durch Bienen, Pfropfen |
| Juni | Junifruchtfall; bei starkem Behang von Hand ausdünnen |
| Juli bis August | Sommerschnitt, Okulieren, erste Frühsorten ernten |
| September bis Oktober | Haupternte, Einlagern |
| November bis Dezember | Pflanzzeit für wurzelnackte Bäume, Stammanstrich gegen Frostrisse |

## Pflückreife

Eine Frucht ist pflückreif, wenn sie sich mit einer leichten Drehung vom Fruchtholz löst und die Kerne braun sind. Pflückreif ist nicht dasselbe wie genussreif: Viele Lagersorten schmecken erst nach Wochen im Lager.
